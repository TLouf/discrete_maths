# Discrete mathematics @ UC3M

This repo collects the notes and exercises I prepared for a first year discrete mathematics course at the [Universidad Carlos III de Madrid](https://uc3m.es).
Compilation requires [`typst >= 0.14`](https://typst.app/open-source/) installed, and example commands can be found in `.zed/tasks.json`.
Below is a list of the bachelors in which I taught the course each year.

## 2026

- [Bachelor in Data Science and Engineering](https://www.uc3m.es/bachelor-degree/data-science)
- [Bachelor in Artificial Intelligence](https://www.uc3m.es/bachelor-degree/artificial-intelligence)
